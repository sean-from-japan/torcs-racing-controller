# Provenance

Where every file here came from, what was deliberately left out, and what was checked
before this repository was made public.

This is a curated extraction from a private project repository, not that repository with
files deleted. It has its own initial commit, so nothing listed under *Excluded* is
recoverable from the history either.

## Included

| Path | Origin |
|---|---|
| `src/controller.py` | Extracted from the training script and the runner, which each held an identical inline copy |
| `src/run_eval.py` | The project's evaluation runner, refactored onto `controller.py` |
| `src/train_nn_ars.py` | The project's ARS training loop, refactored onto `controller.py` |
| `src/train_cma_5param.py` | The project's stage-3 CMA-ES script; import and output paths only |
| `src/train_cma_sector.py` | The project's stage-4 CMA-ES script; import and output paths only |
| `src/analyze_track.py` | The project's track-geometry extractor |
| `src/torcs_env.py`, `src/make_figure.py` | Written for this repository |

| `docs/corkscrew_analysis.md` | Generated by `src/analyze_track.py` |

All of it is my own work. Third-party components are named in the
[Attribution](../README.md#attribution) table and none of them is redistributed here.

- No `.env`, credential file or config with embedded secrets.
- No internal URLs, hosting addresses or client contact details.
- `results/` holds numeric parameters and lap times only.
- No personal data beyond my own name and affiliation.

module with an industry client, and I have not confirmed who holds rights over coursework
output. Adding a licence I am not certain I can grant would be worse than leaving the

## Derived track data

`results/corkscrew_segments.json` and `docs/corkscrew_analysis.md` are geometric
measurements extracted by `src/analyze_track.py` from the Corkscrew track definition that
ships with TORCS (GPL-2.0). They contain no TORCS code and no track file — only numbers —
and they are kept because the s35 diagnosis is an argument from that data, not an
anecdote. Regenerate them from your own install if you would rather not take mine.
